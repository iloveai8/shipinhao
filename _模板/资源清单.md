# 资源清单 · 【产品名】

> 目录：`E:\视频号\【产品名】\`

## 一、结构（所有产品通用）

```
产品名\
├─ 执行方案.md     怎么做的完整步骤
├─ 资源清单.md     有什么、缺什么（本文件）
├─ 提示词文案.md   可直接复制的提示词
├─ 素材\           产品照、首帧图、尾帧截图
├─ 产出\           视频片段、成片、封面
└─ 合规\           证照、授权、包装背面（商用才需要）
```

## 二、素材（现状）

| 文件 | 内容 | 用途 |
|---|---|---|
| `素材\产品-01-【】.jpg` | 【】 | 【】 |

**还缺**

| 文件 | 怎么来 |
|---|---|
| `素材\首帧-【场景名】.jpg` | 文生图（用 提示词文案.md 第一节） |
| `素材\段N尾帧.jpg` | 各段出片后截屏 |

## 三、产出（还缺）

| 文件 | 说明 |
|---|---|
| `产出\段1.mp4` … | 各段生成 |
| `产出\【产品名】-15s-v1.mp4` | 成片 |
| `产出\封面-9x16.jpg` | 封面 |

## 四、合规（商用才需要）

| 文件 | 为什么 |
|---|---|
| `合规\包装背面.jpg`（配料表、净含量、生产商、SC 编号） | 宣传数据要有依据 |
| `合规\规格.txt`（规格、克重、价格） | 台词要对得上 |
| 营业执照 / 食品资质 | 平台审核 |
| 广告标注信息 | 广告需可识别 |
| 肖像授权 / 场地授权 | 用真人或实景才需要 |
