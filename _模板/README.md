# 模板使用说明

## 新产品开工：3 步

1. 复制整个 `_模板` 文件夹 → 粘贴到 `E:\视频号\` → 改名成产品名（例：`某某-某某`）
2. 依次填三个文件：`执行方案.md` → `提示词文案.md` → `资源清单.md`
3. 把产品图丢进 `素材\`，开始生成

## 三个文档各管什么

| 文件 | 回答什么问题 | 什么时候看 |
|---|---|---|
| `提示词文案.md` | 粘贴什么进模型 | 生成时 |
| `执行方案.md` | 每一步怎么做、参数怎么选 | 全程 |
| `资源清单.md` | 有什么、还缺什么 | 开工前、收尾时 |

## 两个文件夹

| 文件夹 | 放什么 | 判断标准 |
|---|---|---|
| `素材\` | 产品照、首帧图、尾帧截图 | 生成之前就存在的 |
| `产出\` | 视频片段、成片、封面 | 生成/剪辑之后才有的 |
| `合规\` | 证照、授权、包装背面 | 商用才用到 |

## 命名规范

`类型-序号-描述.扩展名`

- 素材：`产品-01-包装.jpg`、`首帧-场景名.jpg`、`段1尾帧.jpg`
- 产出：`段1.mp4`、`产品名-15s-v1.mp4`、`封面-9x16.jpg`
