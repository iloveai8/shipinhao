## 七、操作步骤

1. 豆包出首帧图（别在要花积分的平台出图）
2. 上传首帧 → 粘段 1 → 生成 → 下载
3. 截段 1 尾帧 → 当段 2 首帧 → 粘段 2 → 生成
4. 截段 2 尾帧 → 当段 3 首帧 → 粘段 3 → 生成
5. 剪映拼接 → 裁到目标时长 → 加实拍插入 → 导出
