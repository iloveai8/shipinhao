## 一、结构（所有产品通用）

```
【product-slug】\
├─ execution-plan.md   执行方案：参数、时间轴、步骤、积分止损、验收、合规
├─ prompts.md          可直接复制的提示词
├─ resources.md        有什么、缺什么（本文件）
├─ assets\             素材：产品照、首帧图、尾帧截图

```

| 文件 | 为什么 |

| `compliance\package-back.jpg`（配料表、净含量、生产商、SC 编号） | 宣传数据要有依据 |

| `compliance\ad-label.md` | 广告需可识别 |
| `compliance\portrait-authorization.pdf` / `venue-authorization.pdf` | 用真人或实景才需要 |
